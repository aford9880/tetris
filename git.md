# git.md — правила коммитов

1. Пиши сообщение в формате:
   `тип: описание`

2. Используй один из типов:
    `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`, `ci`, `perf`, `revert`

3. Описание — на русском языке, кратко, понятно.

4. Начинай с глагола в повелительном наклонении:
    *Добавлен*, *Исправлен*, *Обновлён*, *Удалён*, *Перемещён*, *Переименован*

5. Не пиши:

   - "Добавил", "Исправил" (не повелительное наклонение)
   - "change", "update", "fix bug" без пояснений
   - сленг: "пофикшено", "залил", "работает"

6. Длина строки — до 72 символов.

7. Примеры:
    `feat: добавлен новый агент для обработки изображений`
    `fix: исправлена ошибка при обработке пустого списка`
    `docs: обновлена документация по настройке проекта`
    `chore: обновлены зависимости в requirements.txt`
